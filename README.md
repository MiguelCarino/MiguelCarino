### Free tools at [carino.systems](https://carino.systems)

Everything runs in your browser: nothing to install, no account, and your files never leave your computer.

**IT and networks**
- [Hardware](https://hardware.carino.systems/) — MAC address vendor lookup, Dell service tags, warranty and driver links
- [Ping](https://ping.carino.systems/) — latency, jitter and packet loss, and saved ping logs read back
- [Test](https://test.carino.systems/) — network diagnostics: NAT, WebRTC, DNS-over-HTTPS, speed
- [Netplan](https://netplan.carino.systems/) — Linux network configs without YAML mistakes
- [Topo](https://topo.carino.systems/) — draw network diagrams
- [Setup](https://setup.carino.systems/) — one command that sets up Linux, Windows or macOS

**Files and privacy**
- [Metadata](https://metadata.carino.systems/) — see and edit file metadata, strip GPS from photos
- [Media](https://media.carino.systems/) — PDF to image, OCR, image and audio conversion
- [Password](https://password.carino.systems/) — strong passwords, shared safely
- [Hash](https://hash.carino.systems/) — watch SHA-256 work step by step

**Everyday**
- [Vitae](https://vitae.carino.systems/) — résumé builder with PDF export
- [Subs](https://subs.carino.systems/) — fix out-of-sync subtitles and lyrics
- [Time](https://time.carino.systems/) — world clock, UTC and Unix epoch
- [Learn](https://learn.carino.systems/) — interactive lessons: assembly, Bash, Git, networking, regex

**For fun**
- [CyberCity](https://cybercity.carino.systems/) — walkable worlds drawn in text characters
- [Asobi](https://asobi.carino.systems/) — Shogi and Hanafuda in the browser
- [ButterEye](https://butter.carino.systems/) — smooth-motion video for mpv
